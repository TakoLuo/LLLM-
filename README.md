# Sparse Recovery of Hyperspectral Signal — Bilingual Paper Guide

這是獨立的新網站專案，不會改動原本的 `sparse-recovery-report`。

## 48 個知識頁

首頁保留論文總覽，再以八組、48 張卡片開啟獨立的 `#concept-01` 至 `#concept-48` 網址。每頁提供中英雙語概念、三步講解、生活例子、可展開名詞、互動示意、解讀界線與論文來源。搜尋支援中英文名詞，並可按研究階段篩選。

- `dist/concept-data.js`：48 個人工撰寫的中英內容與來源。
- `dist/concepts.js`：頁面、目錄、互動與數值計算。
- `dist/concepts.css`：新增頁面與手機版排版。
- 原有長篇詳解與互動保留為各頁的延伸入口；舊網址仍可使用。
- 合成示意與原文 Table 1 數據分開標示。新互動不是作者程式重現。
- `node scripts/check-concepts.cjs`：檢查內容完整度、真零空間、OMP 單調下降／係數重算，以及單原子 SVD 的最佳方向。

## 本機預覽

網站不需要安裝套件或建置；直接開啟 `dist/index.html`，或在專案根目錄啟動靜態伺服器：

```powershell
python -m http.server 4173 --directory dist
```

接著瀏覽 `http://127.0.0.1:4173/`。

## 設計原則

- 依序建立光譜、RGB、高光譜資料、同色異譜、先驗、稀疏表示、成對字典、公式、演算法與實驗的概念。
- 互動是共同觀察工具，不設理解測驗、分數或答題門檻。
- 教學示意與論文實驗數字分開標示。
- RGB 壓縮器可自由選擇 400–700 nm 中心波長，並比較調整前後的 ΔR、ΔG、ΔB；550 nm 只是快速範例，不被誤寫成論文指定波長。
- 式（6）只說明 RGB 回投影一致，不把它誤稱為真實光譜證明。
- 原論文 Table 3 的 `0.557` 依原文保留並標示疑點，不自行更正。
